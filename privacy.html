Privacy & Data Use

TMH Market Research · Last updated September 27, 2026

Application scope

TMH Market Research is currently a private internal research application operated by The Midnight Hive. It is not a public consumer service and does not provide public user accounts.

Marketplace data

When Etsy access is approved, the application is intended to request Etsy data through the official Etsy Open API and only within the use case, access level, endpoints, scopes, and limits approved for the application. The data is used to prepare internal market-research and product-planning materials.

Private member data

The current research purpose is not designed to collect private buyer information, private seller messages, payment information, or other private member data. If the application purpose changes in the future, the integration and this notice will be reviewed before additional data or permissions are requested.

Credentials and security

API credentials, access tokens, shared secrets, and other authentication material are treated as confidential. They are not published on this website or committed to public source code.

Retention and deletion

Research data is retained only as reasonably necessary for the approved internal workflow and is handled subject to the source platform's applicable caching, retention, deletion, and API requirements. Data that is no longer needed for the approved purpose is removed from the research workflow in accordance with those requirements.

Sharing

The application is not intended to sell Etsy data or make an Etsy-derived dataset available to the public. Access to internal research materials is limited to authorized collaborators supporting the stated research purpose.

Support and compliance

Questions, privacy requests, or compliance requests relating to the application are handled through the developer contact information registered with the Etsy application.

The term 'Etsy' is a trademark of Etsy, Inc. This application uses the Etsy API but is not endorsed or certified by Etsy, Inc.
